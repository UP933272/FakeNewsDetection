# Fake News Detection Tool

## Welcome to my final year project!
I created a fake news detection tool! To score and catch fake news. This tool uses a news based content detection technique when evaluating whether the user input is fake news or not.


### General Instructions

- Step 1: Setup Python Virtual Enviroment and install requirements.txt
- Step 2: Run the command: "source venv/bin/activate" in your terminal


### Sprint 1 Basic App UI Configuration or Sprint 2 Advanced UI Configuration

To run this program follow these instructions:

- Step 1: Run the train_model.py file for first time use or to update your model with the latest dataset
- Step 2: To run basic UI interface run the predict.py file OR to run the advanced Streamlit Web Application run the app.py file

### Sprint 3 Advanced Improved Version Configuration

 - Step 1: Run the file prepare_dataset.py - You can use this function to combine online datasets
 - Step 2: Run the file train_model_v2.py
 - Step 3: Run the file app_improved.py
